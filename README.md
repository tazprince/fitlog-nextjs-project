# FitLog

FitLog is a modern workout planning application that helps users discover workouts, create a personal workout plan, save favorite exercises, and track basic workout statistics in one place.

## Technologies Used

* Next.js
* React
* Tailwind CSS
* DaisyUI
* JavaScript
* Lucide React
* Sonner
* Next Image

## Key Features

1. **Workout Library**
   Browse different workouts with details such as equipment, difficulty, duration, calories, rating, and muscle groups.

2. **Workout Details**
   View complete information about a workout, including instructions, sets, reps, duration, calories, and required equipment.

3. **Personal Workout Plan**
   Add workouts to your personal plan and see the total number of exercises, workout duration, and calories.

4. **Save Workouts**
   Save workouts for later and manage them separately from your daily workout plan.

5. **Remove & Track Workouts**
   Remove workouts from your plan or saved list and mark planned workouts as completed.
